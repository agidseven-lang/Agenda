## Arquitetura (aditiva, produção — não é teste)
Duas flags (fonte única em `firebaseAuthBridge.js` → `FLAGS`):
`DESKTOP_FIREBASE_AUTH_ENABLED=true`, `DESKTOP_FIREBASE_AUTH_REQUIRED=false`.

- **Contexto correto:** o Firestore REAL das operações interativas roda no **renderer**
  (`index.html`: `firebase.initializeApp` + `firebase.firestore()`). O bridge assina no **mesmo app
  Firebase default** do renderer (`firebase.auth().signInWithCustomToken`) — assim o SDK enviará
  `request.auth` no futuro. Não cria segunda instância Firebase. (O main tem um Firestore separado só
  para o listener de SLA em background; auth do listener do main fica para fase futura, quando as
  Rules endurecerem.)
- **Fluxo** (em `startApp` → cobre login E bootstrap/reabertura via `authSelf`):
  loginUser (main, sessão server-side) → `issueFirebaseAuthToken` (Bearer, no main) → Custom Token
  efêmero → `signInWithCustomToken` (renderer) → confirma `currentUser.uid == uid` da sessão →
  segue o carregamento normal. Nenhuma tela/ação extra.
- **Fail-open (REQUIRED=false):** rede/timeout/endpoint/Firebase indisponível → a Desktop continua
  pelo contrato atual; diagnóstico sanitizado; retry com backoff exponencial capado; sem loop; sem
  expor token.
- **Fail-closed (segurança):** uid Firebase ≠ uid da sessão / usuário desativado (403) / sessão
  inválida (401) → `signOut` + limpa sessão + volta ao login; nunca mostra dados de outro usuário.
  (`currentUser` nulo é tratado como transitório — fail-open — para não deslogar por glitch de SDK.)
- **Token:** o Custom Token vive **só em memória** (argumento de `signInWithCustomToken`); nunca
  persistido/logado/localStorage/arquivo/DevTools. O Firebase SDK gerencia a renovação do ID Token.
- **Logout / troca de usuário:** `firebase.auth().signOut()` + limpeza + listeners parados; a nova
  sessão nunca mostra dados da anterior.
- **Diagnóstico sanitizado:** estados `firebaseAuthBridge.{started,success,retry,signedOut,uidMismatch,
  disabled,giveUp}` (uid mascarado; nunca token/senha/HMAC/ID Token/UID completo desnecessário).
