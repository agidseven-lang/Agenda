Ex.: `android/f43a-play-release-readiness`.

**PARAR (NO-GO) se qualquer uma ocorrer — invariante violado ⇒ um componente deixa de ser ZERO:**
1. **PARE** se F4.3A introduzir qualquer alteração fora de `android-native-beta/docs/**` — em `android-native-beta/app/**`, `desktop/**`, `cloudflare-worker.js`, `functions/**`, Rules ou `.github/workflows/**` (viola I1).
2. **PARE** se o branch for `main` ou `f42e`, ou se qualquer trigger de `push`/`workflow_dispatch` for disparado por F4.3A (viola I2).
3. **PARE** se o AAB/APK for recompilado ou o SHA-256 divergir de `1c14d39188…320a83` / `dca77db…` (viola I3 — builds assinados não são bit-a-bit reprodutíveis).
