## 1. Legenda de direção (o que é "bom")
Para cada critério, a coluna **Dir.** indica qual sentido é favorável:
- **↑** = maior é melhor (Segurança/ganho, Rollback, Listeners, Tempo real, Facilidade de testes, Compatibilidade gradual).
- **↓** = menor é melhor (Risco de regressão, Impacto na Desktop/Android/Card Premium/Notificações, Complexidade, Prazo, Custo operacional).

## 5. Ordem sugerida das subfases (nenhuma inicia automaticamente)
